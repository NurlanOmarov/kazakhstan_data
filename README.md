# Поиск по базе жителей Казахстана

Быстрый сервис поиска по базе ~16.3 млн записей.

## Стек и почему так

- **БД: SQLite + FTS5.** Выбран вместо PostgreSQL: данные статичные, нагрузка
  только на чтение, один файл без сервера БД, полнотекстовый индекс FTS5
  компактнее и быстрее, чем `pg_trgm`-индексы Postgres. Подробности и
  альтернативы — см. ниже и в [SEARCH_DESIGN.md](SEARCH_DESIGN.md).
- **Бэкенд: FastAPI** (`app.py` — тонкий слой API, `search.py` — логика поиска).
- **Фронтенд: React + TypeScript (Vite)** в [`frontend/`](frontend/), адаптив
  под мобильные (таблица на десктопе, карточки на телефоне).

## Возможности поиска

- По **ФИО одной строкой**, по отдельным полям, по **ИИН**, телефону, дате
  рождения, адресу; поля комбинируются по И.
- **Устойчивость к опечаткам** — у пользователя И в самой базе
  (нечёткий поиск, расстояние Левенштейна).
- **Казахско-русские варианты букв** (Ә/А, Қ/К, Ө/О, …), регистр, формат
  телефонов — нормализуются.
- В ответе `mode`: `exact` / `fuzzy` / `none` — UI подсвечивает нечёткий поиск.

Полное описание параметров и работы с качеством данных — [SEARCH_DESIGN.md](SEARCH_DESIGN.md).

## Запуск (локально)

Нужен Python 3.12 (3.14 ломает venv) и Node 20+.

```bash
# 1. Бэкенд
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app:app --host 127.0.0.1 --port 8000

# 2. Фронтенд (для разработки, с hot-reload)
cd frontend
npm install
npm run dev          # http://localhost:5173, проксирует /api на :8000
```

Для продакшен-режима соберите фронт — тогда бэкенд сам отдаёт готовый UI на `/`:

```bash
cd frontend && npm run build
.venv/bin/uvicorn app:app --port 8000   # открыть http://127.0.0.1:8000
```

Путь к БД можно задать переменной `KZ_DB_PATH` (по умолчанию `./kazakhstan_data.db`).

## Тесты

```bash
.venv/bin/python -m pytest                 # бэкенд (13 тестов)
cd frontend && npm test                    # фронтенд (Vitest + RTL, 6 тестов)
```

## Структура

```
app.py              FastAPI: /api/search, /api/health, отдача фронта
search.py           логика поиска (FTS5 + нечёткий), тестируется отдельно
tests/              pytest для бэкенда
frontend/           React + TypeScript (Vite)
reference/          скрипты пересоздания БД из CSV (на будущее)
SEARCH_DESIGN.md    дизайн параметров поиска и работа с качеством данных
kazakhstan_data.db  база (~14 ГБ, в git не коммитится)
```
